# VardrGate v0.2.0

Security and authorization-testing update. Requires Go 1.25 or newer for source
installation; official archives are built with Go 1.27.3.

## Upgrading

- Runner 0.54.0 requires this release or a newer Gate with `run --literal-job`.
  Install the matching platform archive from this release and ensure `vardrgate`
  is on PATH. Confirm `vardrgate version` prints `v0.2.0`.
- `serve` now binds to `127.0.0.1` by default. Set `VARDRGATE_HOST` explicitly
  for another interface. Configured bearer keys now protect `/tests/execute`
  as well as queue endpoints. `/health` remains public.
- Private-target opt-ins remain available. Metadata/link-local and 0.0.0.0/8
  destinations are always blocked. Shared/benchmark ranges require private opt-in;
  the well-known NAT64 prefix and 6to4 receive embedded-IPv4 checks.

## Changes

- Literal job input prevents environment substitution for callers that already
  resolve credentials; standalone jobs keep their existing default behavior.
- Credential-substitution failures omit credential values from errors.
- Strict identity preflight and inconclusive-result CI gating.
- Scoped denial profiles, explicit write verification and saved regressions.
- JSON, text, Markdown and SARIF outputs, policy/suite execution and reviewed
  discovery scaffolds. Generated hypotheses remain non-executable until reviewed.
- Commit-pinned CI actions and reachable-vulnerability checks.

See the [changelog](../../CHANGELOG.md) for the full changes and the
[strict-CI guide](../strict-ci.md) for explicit gating options. Findings still
require human verification. The source-built distribution pins are updated
separately; this release does not change an existing installation.

Archives include licenses, SHA256SUMS and GitHub build provenance. Verify the
downloaded archive before extracting it. Archives are not OS code-signed.
