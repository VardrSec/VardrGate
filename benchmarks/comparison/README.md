# Comparison utilities

These optional utilities operate on explicitly selected local builds and
synthetic fixtures. No historical measurements or worker-comparison reports are
bundled. Use each script's command-line help before choosing a target or output.

`compare.py` generates `four-versions.json`; `compare_vampi.py` requires that
local generated file. Generate it first rather than treating absent historical
results as current measurements. Retain outputs privately. Results apply only
to the selected fixtures and do not establish general detection accuracy.
